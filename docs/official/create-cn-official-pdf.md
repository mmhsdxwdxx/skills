# create-cn-official-pdf

## Quickstart

```bash
npx skills@latest add mmhsdxwdxx/skills --skill create-cn-official-pdf
```

[Source](https://github.com/mmhsdxwdxx/skills/tree/main/skills/official/create-cn-official-pdf)

## 它做什么

把公文内容转换为符合 GB/T 9704—2012 基线的可打印 PDF，并把字体替代、印章缺失、附件不完整等问题显式写入验收报告。它不是简单套用“仿宋三号”，而是同时控制 A4 版心、行字网格、红头、标题层级、落款、版记和单双页页码。

## 什么时候使用

你可以显式调用 `$create-cn-official-pdf`；当任务涉及通知、请示、报告、函、批复、纪要、红头文件或公文 PDF 核验时，模型也可以自动调用。

## 前置条件

正式印发需要本机具有获得授权的准确字体和合法的机关版头、印章素材。技能不会生成或仿造印章；缺少方正小标宋时只能产出带警告的草稿。

## 标准、地方规则与工程换算

技能把三者分开记录：国家标准是基线；有效的上级或本机关模板优先；28.8、29 或 30 磅等行距值只是实现 22 行版心的工程参数，不冒充全国统一条文。

## 成功标志

- PDF 为标准 A4，文字可搜索，字体资源可审计。
- 每页已经渲染为图片并完成目视检查。
- 版式偏差和素材缺口没有被静默隐藏。

## 在体系中的位置

这是 `official` 分类中的基础渲染与验收能力。后续可在同一分类增加公文起草、合法性审核、政策解读和机关模板适配技能，并保持触发边界互不重叠。
